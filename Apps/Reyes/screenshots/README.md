# Screenshots necesarios

Por favor, añade capturas de pantalla de la aplicación en formato PNG (1280x720 recomendado):

## Capturas requeridas:

1. **dashboard.png** - Vista principal del dashboard con listas de regalos
2. **list.png** - Vista de una lista de regalos individual
3. **profile.png** - Pantalla de perfil de usuario
4. **login.png** - Pantalla de inicio de sesión/registro

## Cómo tomar las capturas:

1. Abre la aplicación en http://localhost:9050
2. Navega a cada sección
3. Toma captura con Windows (Win + Shift + S) o herramienta de screenshots
4. Guarda con el nombre correspondiente
5. Reemplaza este README.md

## Alternativa temporal:

Si necesitas publicar ya, puedes usar placeholders o la misma imagen de icon.png para todas mientras preparas las capturas reales.
